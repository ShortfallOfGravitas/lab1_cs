# Лабораторна робота №1: Візуальне моделювання фігур Ліссажу

Цей проєкт реалізує інтерактивну модель гармонічних коливань за допомогою кросплатформного фреймворку **Avalonia UI** з дотриманням патерну **MVVM**.

## 🛠 Вимоги та запуск
* Проєкт створено для **.NET 10** (як зазначено в методичних вказівках).
* Жодних додаткових інструментів чи розширень для Avalonia встановлювати **не потрібно**. Усі необхідні бібліотеки (NuGet-пакети) завантажаться автоматично.

### 🚀 Як запустити у Visual Studio:
1. Відкрийте Visual Studio 2022 та виберіть **"Open a project or solution"**.
2. Виберіть файл проєкту `LissajousApp.csproj` (або просто відкрийте папку репозиторію).
3. Дочекайтеся, поки IDE автоматично відновить NuGet-пакети (зазвичай займає кілька секунд).
4. Переконайтеся, що стартовим проєктом обрано `LissajousApp`.
5. Натисніть кнопку **Run**
